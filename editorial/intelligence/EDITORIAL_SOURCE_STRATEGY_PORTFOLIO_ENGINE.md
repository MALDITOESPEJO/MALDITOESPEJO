# EDITORIAL SOURCE STRATEGY & PORTFOLIO ENGINE

## 1. Purpose

This engine governs the source ecosystem as a portfolio rather than as a collection of isolated sources.

Its purpose is to ensure that MALDITOESPEJO has the right combination of:

- authoritative sources;
- primary evidence;
- independent lineages;
- detection channels;
- verification capabilities;
- geographic coverage;
- institutional coverage;
- temporal coverage;
- specialist expertise;
- continuity and fallback capacity.

## 2. Core principle

> The objective is not to maximize the number of sources. The objective is to maximize reliable editorial capability while minimizing hidden dependency and avoidable operational risk.

## 3. Portfolio model

The portfolio is evaluated across:

`SOURCE → LINEAGE → FUNCTION → TOPIC → JURISDICTION → EVENT CLASS → EVIDENCE CLASS`

A source belongs to a portfolio because it performs one or more identifiable functions.

## 4. Strategic source roles

- `PRIMARY_AUTHORITATIVE`
- `PRIMARY_OBSERVATIONAL`
- `SPECIALIST_DATA`
- `LOCAL_PRIMARY`
- `INDEPENDENT_SECONDARY`
- `DISCOVERY`
- `CONTEXT`
- `RESILIENCE_FALLBACK`

Roles are not mutually exclusive.

## 5. Portfolio dimensions

### Authority coverage
Does the portfolio contain authoritative sources for consequential fact classes?

### Independence diversity
Does the portfolio contain genuinely independent evidentiary lineages?

### Detection diversity
Can material events be detected through more than one appropriate pathway?

### Verification diversity
Can central claims be verified without relying on a single source lineage?

### Geographic diversity
Does the portfolio adequately cover relevant jurisdictions and local contexts?

### Institutional diversity
Does it cover the institutions and actors whose decisions generate material events?

### Temporal diversity
Does it provide real-time, scheduled, historical and archival capability where required?

### Methodological diversity
Are important conclusions dependent on one methodology?

### Operational diversity
Can the system continue when an endpoint, domain, feed or provider fails?

## 6. Portfolio concentration

Concentration must be assessed at lineage level, not merely source-count level.

Examples of false diversity:

- ten outlets reproducing one agency dispatch;
- several feeds derived from one dataset;
- multiple websites embedding the same primary document;
- different APIs exposing the same underlying database.

`10 SOURCES ≠ 10 INDEPENDENT LINEAGES`

## 7. Strategic dependency

A dependency becomes strategically significant when loss or degradation of a lineage materially affects:

- verification;
- detection;
- geographic coverage;
- institutional coverage;
- a critical event class;
- a high-priority editorial section;
- continuity of a consequential investigation.

## 10. Strategic portfolio questions

The portfolio review should answer:

1. What critical facts depend on one lineage?
2. Where is redundancy real rather than apparent?
3. Which sources provide unique primary evidence?
4. Which sources are valuable only for discovery?
5. Which gaps remain after acquisition efforts?
6. Which source failures would materially affect publication capability?
7. Which topics have excessive concentration?
8. Which jurisdictions lack local or primary evidence?
9. Where does one methodology dominate?
10. Which sources should be strengthened, replaced or supplemented?

## 11. Portfolio optimization

Optimization may involve:

- acquiring an independent primary source;
- adding a local source;
- adding a specialist dataset;
- adding a second detection pathway;
- adding an archival source;
- reducing duplicate feeds;
- narrowing low-value sources;
- improving endpoint resilience;
- creating evidence-preservation procedures.

Optimization must not be interpreted as maximizing numerical source count.

## 12. Strategic redundancy

Redundancy is valuable only when it contributes meaningful independence or continuity.

Three useful categories:

### `EVIDENTIARY_REDUNDANCY`
Independent sources can establish or corroborate the proposition.

### `DETECTION_REDUNDANCY`
Multiple pathways can discover the event.

### `OPERATIONAL_REDUNDANCY`
Alternative channels permit continued access when infrastructure fails.

These forms of redundancy should be assessed separately.

## 13. Unique-source exception

Some facts inherently have a unique authoritative source, such as:

- an official judicial ruling;
- an institution's own unpublished administrative decision;
- an official electoral result;
- a regulator's own enforcement action.

The absence of a second primary source is not automatically a portfolio failure.

The system should instead document `CRITICAL_UNIQUENESS` and strengthen contextual/corroborative verification around the unique source.

## 14. Source portfolio by editorial function

Every strategic review should map sources to functions such as:

- breaking detection;
- primary confirmation;
- quantitative verification;
- OSINT verification;
- geolocation;
- satellite analysis;
- legal verification;
- election verification;
- conflict analysis;
- humanitarian verification;
- cybersecurity verification;
- scientific verification;
- contextual analysis.

## 15. Portfolio balance

A healthy portfolio should avoid simultaneous dependence on:

- one provider;
- one methodology;
- one geography;
- one institutional viewpoint;
- one technical endpoint;
- one secondary reporting lineage.

Balance does not mean artificial symmetry. It means sufficient capability for the relevant editorial risk.

## 16. Portfolio review triggers

Strategic review is required after:

- major source retirement;
- major source acquisition;
- critical source failure;
- material source change;
- discovery of common lineage;
- new editorial section or event class;
- major geographic expansion;
- major regulatory/electoral/conflict event requiring new evidence capability;
- persistent verification gaps.

## 17. Portfolio actions

Possible actions:

- `MAINTAIN`
- `STRENGTHEN`
- `DIVERSIFY`
- `ACQUIRE`
- `REDUCE_DUPLICATION`
- `RESTRICT`
- `REPLACE`
- `ARCHIVE`
- `ACCEPT_UNIQUENESS`
- `ESCALATE`

## 18. Governance constraints

The portfolio engine must not:

- rank political viewpoints;
- infer truth from source quantity;
- equate institutional diversity with evidentiary independence;
- replace human editorial judgment;
- automatically remove sources;
- substitute secondary coverage for missing primary evidence without disclosure.

## 19. Relationship with previous engines

`COVERAGE/GAP → ACQUISITION → PERFORMANCE → HEALTH → CHANGE IMPACT → RESILIENCE → PORTFOLIO STRATEGY → GOVERNANCE`

The portfolio layer therefore acts as the strategic control plane for the source ecosystem.

## 20. Core principle

> A strong newsroom source system is not the one with the most sources; it is the one that can detect, verify, contextualize and preserve consequential facts without hidden dependence on a single evidentiary lineage.
