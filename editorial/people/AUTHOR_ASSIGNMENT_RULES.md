# Reglas de asignación de autoría

## Propósito

Este documento convierte la política de autoría en una regla operativa para la producción de piezas.

La regla ordinaria es determinista:

`SECTION → DEFAULT AUTHOR`

La autoría declarada en una pieza debe coincidir con el responsable de esa sección, salvo excepción editorial registrada.

## Mapa vigente

| Sección | Autor/a ordinario/a |
|---|---|
| Actualidad | Iria Valcárcel Montoro |
| Política | Bruno Salvatierra Ledesma |
| Economía | Nerea Villacorta Beltrán |
| Sociedad | Ariadna Soler Montalbán |
| Mundo | Gael Santacruz Ferrán |
| Tecnología | Vera Alcántara Robledo |

Todas las identidades del mapa son personajes editoriales ficticios creados para MALDITOESPEJO.

## Reglas de validación

1. Toda pieza publicable debe tener `section` y `author`.
2. `section` debe corresponder a una sección editorial válida.
3. `author` debe coincidir con el autor ordinario de la sección, salvo excepción documentada.
4. Una excepción no se considera válida solo porque el nombre aparezca en el frontmatter: debe existir una decisión editorial que la justifique.
5. La autoría no sustituye la verificación de fuentes.
6. El autor no debe incorporar como fuente pública un medio utilizado únicamente para descubrir la historia.
7. Las fuentes no aparecen como listado dentro del texto público.
8. El contenido público debe distinguir con claridad hechos, declaraciones, contexto y cuestiones todavía no resueltas.
9. MALDITOESPEJO no presenta opiniones institucionales propias dentro de las noticias.

## Control previo a publicación

Antes de publicar una pieza, el editor debe poder responder afirmativamente:

- ¿Tiene sección?
- ¿Tiene autor/a?
- ¿La autoría coincide con la sección?
- Si no coincide, ¿existe una excepción documentada?
- ¿La información publicada procede de fuentes realmente examinadas y verificadas?
- ¿La redacción permite entender qué sabemos, qué se afirma y qué todavía no sabemos?

## Regla para automatización futura

Cuando el sistema de publicación incorpore validación automática, la comprobación deberá tratar una discrepancia entre `section` y `author` como **bloqueo editorial**, no como advertencia informativa.

La automatización puede comprobar la coherencia; no puede decidir por sí sola una excepción de autoría.

## Principio editorial

> **La investigación puede ser compleja; la explicación no debe serlo.**
