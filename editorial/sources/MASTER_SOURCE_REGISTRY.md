# MALDITOESPEJO — MASTER SOURCE REGISTRY

## Estado
Consolidación editorial de las rondas de trabajo realizadas hasta la Ronda 20.

## Principio rector
La automatización detecta señales; no convierte automáticamente una señal en una verdad editorial. Se separan detección, evidencia, corroboración, interpretación y publicación.

## Arquitectura
SOURCE → CHANNEL → FEED → TOPIC → EVENT / CLAIM / DATA → SIGNAL ENGINE → CROSS-SOURCE CORRELATION → VERIFICATION CHAIN → EDITORIAL PRIORITY → HUMAN EDITOR → PUBLICATION

## Prioridad editorial
- A+ = inmediata / alerta de alta prioridad
- A = revisión prioritaria
- B = vigilancia ordinaria
- C = contexto

## Autoridad
Las fuentes primarias/oficiales tienen prioridad para hechos institucionales. Agencias y medios funcionan como discovery, breaking news, cross-check, contexto o análisis. Los fact-checkers no sustituyen la fuente primaria.

## Estado de verificación de fuente
- SOURCE_VERIFIED = YES: institución/fuente comprobada.
- CHANNEL_VERIFIED = PENDING: endpoint técnico pendiente de comprobación real.

## Reglas críticas
1. PRIMARY ≠ SECONDARY.
2. FACT-CHECK ≠ PRIMARY SOURCE.
3. EVENT ≠ CLAIM ≠ NARRATIVE.
4. INSTITUTIONAL_EVENT ≠ NEWS ARTICLE.
5. TRACKING DATA ≠ prueba jurídica absoluta.
6. TIV de SIPRI ≠ valor monetario de una transferencia.
7. Si una fuente primaria y una secundaria divergen: EDITORIAL_CONFLICT_ALERT + revisión humana.
8. No marcar un endpoint como verificado sin comprobarlo.
9. Toda afirmación relevante debe poder reconstruirse hasta su evidencia.
10. La publicación final siempre queda bajo control editorial humano.
