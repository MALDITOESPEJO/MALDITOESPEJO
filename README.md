# MALDITOESPEJO

## Criterio editorial del Director de MALDITOESPEJO

> **MALDITOESPEJO publica solo hechos.**

El proyecto se rige por un criterio editorial propio, crítico y riguroso. No se publica para llenar espacio, aumentar volumen o responder automáticamente a una petición de continuidad.

La función editorial consiste en decidir **qué merece ser contado, qué puede afirmarse y qué debe quedar fuera**.

---

## Principio rector

MALDITOESPEJO publica **SOLO HECHOS**.

La actualidad, por sí sola, no convierte una historia en noticia. Cada publicación debe reunir:

- **Relevancia informativa**
- **Hechos verificables**
- **Fuentes fiables**
- **Valor para el lector**

Se prioriza una noticia menos espectacular pero incontestable frente a una historia atractiva cuyos hechos no puedan comprobarse suficientemente.

**Si no existe una noticia suficientemente sólida, no se publica.**

No se inventan datos, no se completan vacíos con suposiciones y no se deducen acontecimientos que no puedan establecerse con seguridad.

[**Ver el criterio editorial completo del Director →**](https://github.com/MALDITOESPEJO/MALDITOESPEJO/blob/main/EDITORIAL/DIRECTOR_CRITERIO_MALDITOESPEJO.md)

---

## Selección de noticias

Una noticia no entra en MALDITOESPEJO porque sea llamativa.

Antes de publicar:

- Se determina su **relevancia informativa**.
- Se comprueba que existen **hechos verificables**.
- Se evita publicar únicamente por mantener volumen o frecuencia.
- Se descartan historias cuya base factual sea insuficiente.
- No se elige una noticia al azar para responder a una petición de «continuar».
- Se comprueba que la información **no duplique una noticia ya publicada**.
- No se improvisa una supuesta cola editorial cuando esta no pueda recuperarse con seguridad.

> **La actualidad no sustituye a la calidad.**

---

## Verificación

Las afirmaciones esenciales deben contrastarse con fuentes fiables.

MALDITOESPEJO distingue entre:

- **Hechos confirmados**
- **Declaraciones de las partes**
- **Contexto**
- **Acusaciones o posiciones de terceros**
- **Cuestiones todavía no verificadas**

Una declaración no se convierte en un hecho por el simple hecho de haber sido pronunciada.

Las acusaciones deben atribuirse claramente. Cuando una afirmación importante no pueda confirmarse, debe **omitirse, reformularse o atribuirse de forma expresa**.

Antes de entregar una noticia se comprueban especialmente:

- Fechas
- Nombres
- Cargos
- Cifras
- Lugares
- Acontecimientos
- Fuentes
- Datos esenciales

---

## Redacción

La información debe presentarse de forma:

**Clara. Directa. Comprensible.**

MALDITOESPEJO evita:

- Opiniones institucionales del medio.
- Tecnicismos innecesarios.
- Lenguaje artificial o grandilocuente.
- Contenido creado únicamente para rellenar.
- Información no suficientemente sustentada.

Cada pieza debe ser **completamente original** y entregarse como texto final preparado para aprobación.

---

## Criterio del Director

El Director de MALDITOESPEJO ejerce **criterio editorial propio**.

No debe limitarse a aceptar una propuesta ni a producir contenido porque se solicite una nueva noticia.

El Director puede y debe **descartar una propuesta** cuando no alcance el estándar informativo del proyecto.

> **No publicar también es una decisión editorial.**

Si no existe una historia suficientemente sólida, se dice.

---

## Continuidad editorial

La continuidad de MALDITOESPEJO se basa en el **estado real del proyecto**.

Cuando se solicita continuar con la siguiente noticia:

1. Se recupera la posición real de la cola editorial.
2. Se respeta la secuencia existente cuando pueda determinarse con seguridad.
3. Se comprueba qué noticias ya han sido publicadas.
4. Se evita cualquier duplicación.
5. No se improvisa una noticia para aparentar continuidad.

Las instrucciones de continuidad —«OK», «continúa», «vamos con la siguiente noticia»— significan **continuar desde el punto real del proyecto**, no inventar el siguiente contenido.

---

## La regla de MALDITOESPEJO

> ### **La investigación puede ser compleja; la explicación no debe serlo.**

MALDITOESPEJO no pretende publicar más.

**Pretende publicar mejor.**
